# Weather App

This project is a full web app where users can create an account, sign in, and check weather by city and state.
https://weather-app-client-20260325123257.vercel.app/login

## What It Does

- Lets users register, verify their email, log in, and manage account settings.
- Shows current weather with simple, readable results.
- Saves each user’s weather lookups so they can view their own history.
- Includes an admin view for managing registered users.
- Supports feedback submissions from within the app.

## Why It Was Built

The goal was to build a practical application that combines:
- user account management,
- reliable weather lookup experience,
- and clean, organized app structure.

## Running Locally

1. Install dependencies in the root, `client`, and `server` folders.
2. Set up environment variables in `server/.env`.
3. Start both apps from the project root:
   - `npm run dev`
4. Open the client at `http://localhost:5173`.
